# 브릭 공방

브라우저에서 즐기는 3D 블럭 쌓기 게임이에요. 설치 없이 링크만 열면 돼요.

**플레이:** https://htcho-max.github.io/brick-gongbang/

## 할 수 있는 것
- 브릭·플레이트·타일·경사·원형·건축·옆붙임·자연·테크닉 부품 120종으로 쌓기 (판 최대 192×192)
- 피규어 9종(시민·경찰·우주인·기사·군인·닌자·사무라이·해적·바이킹), 팔·다리 포즈와 칼·총·활·방패 같은 무기
- 기어 맞물려 돌리기, 바퀴·모터·핸들로 자동차 만들어 운전
- 1인칭으로 피규어가 되어 걸어 다니기, 운전석에서 운전하기
- 예시 작품과 따라 만드는 설계도 (피규어 크기 2층집·탱크·여객선·성채 등)
- 작품은 이 브라우저에 저장하거나 `.json` 파일로 내보내기·가져오기

## 조작
| 키 | 기능 |
|---|---|
| 클릭 / 탭 | 블럭 놓기 |
| 드래그 · 우클릭 드래그 · 휠 | 둘러보기 · 이동 · 확대 |
| R | 회전 |
| M | 옮기기 (한 개 → 묶음 → 묶음 복사) |
| O | 포즈 |
| X | 빼기 |
| B | 공중 조립판 (Q/E 높이) |
| G | 기어·자동차 움직이기 |
| P | 1인칭 |
| Ctrl+Z | 되돌리기 |

## 기술
한 개의 `index.html` 파일로 되어 있어요. Three.js r128(CDN)을 쓰고, 빌드 과정은 없어요.
