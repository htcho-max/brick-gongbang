# 브릭 공방

브라우저에서 즐기는 3D 블럭 쌓기 게임이에요. 설치 없이 링크만 열면 돼요.

**플레이:** https://htcho-max.github.io/brick-gongbang/

## 할 수 있는 것
- 브릭·플레이트·타일·경사·원형·건축·옆붙임·자연·피규어·전투·테크닉·가구·음식·놀이·동물 부품 228종으로 쌓기 (판 최대 384×384, 높이 480플레이트)
- 가구 23종(의자·식탁·소파·침대·책장·옷장·냉장고·싱크대·가스레인지·텔레비전·피아노·변기·욕조·스탠드 등), 음식 23종(사과·수박·피자·햄버거·케이크·김밥·떡볶이·라면·초밥 등), 경첩이 반대인 문·양문
- 전투 부품: 말·대포·깃발·천막·바리케이드·모래주머니·모닥불·가로등
- 지형 도구: 두 곳을 눌러 영역을 정하면 언덕·물·길·모래·풀밭을 한꺼번에 깔거나 영역을 지움
- 밤 모드: 가로등·모닥불·횃불에 불이 들어옴
- 피규어 9종(시민·경찰·우주인·기사·군인·닌자·사무라이·해적·바이킹), 팔·머리·다리(걷기·달리기·무릎·앉기·쓰러짐) 포즈와 칼·총·활·방패 같은 무기
- 기어 맞물려 돌리기, 바퀴·모터·핸들로 자동차 만들어 운전, 프로펠러를 달면 비행기(스페이스로 상승), 물 위에 띄운 배에 모터를 올리면 항해
- 움직이는 세상: ▶ 돌리기를 켜면 걷기·달리기 자세의 피규어가 걸어 다니고, 무기를 든 피규어는 휘두르고 쏘고, 대포가 불을 뿜음
- 타는 놀이기구: 대관람차(사람 크기 곤돌라 16개, 한 칸씩 돌다 멈출 때 걸어 들어가 타고 내림)·롤러코스터와 대형 롤러코스터(384판 둘레 약 1.2km)(승강장에 선 차 쪽으로 걸어가면 타고 1인칭으로 한 바퀴, 끝나면 승강장에 내려 줌)
- 놀이 장치: 엘리베이터(옆 층 바닥 높이마다 멈춤, 1인칭으로 타고 오르내림)·회전문·도개교·관람차·스위치(밟거나 누르면 둘레의 불빛·분수·도개교·엘리베이터·불꽃이 반응)·분수·굴뚝(연기)·불꽃 발사대
- 동물 9종(강아지·고양이·토끼·닭·오리·새·물고기·돼지·소): ▶ 돌리기를 켜면 돌아다니고, 새는 날고, 오리·물고기는 헤엄침
- 🎮 놀이 상자: 보물찾기(별 10개)·숨바꼭질(뜨거워요/차가워요 힌트)·경주(깃발이나 고리를 차례로)·불꽃놀이, 💥 지진·💣 대포알로 부수기(무너진 블럭은 되돌리기로 복구), 날씨(비·눈이 쌓임·무지개), 시간 흐르기(낮→노을→밤→새벽, 밤에는 유리창에 불), 사람·동물 말풍선, 배지 20개
- 📷 사진 · ● 녹화(영상 저장) · 🔊 효과음
- 1인칭으로 피규어가 되어 걸어 다니기(드래그로 방향, W/S 앞뒤 · A/D 옆으로, 벽을 따라 미끄러지고 문틀에 살짝 걸리면 비켜 지나감), 운전석에서 운전하기, 걷기·달리기·질주(G), 1인칭에서 블럭 놓기·빼기(F)
- 예시 작품과 따라 만드는 설계도 — 피규어가 들어가 걸을 수 있는 크기: 2층 주택·탱크·여객선·성채·성 공방전·상점가 거리·해적선·사무라이 마을·여객기·경복궁 근정전·경리단길과 해방촌(남산타워까지)·제주 방주교회·부산 송도해수욕장(구름산책로·해상케이블카)·광화문 광장·서서울미술관과 금나래중앙공원·북촌 한옥마을·용인 한국민속촌·금천구 금나래초등학교·브릭 놀이동산(192×192 전체: 대관람차·롤러코스터·전망대·성·푸드코트·농장)·브릭 놀이동산 384(384×384 전체, 판 둘레를 도는 대형 롤러코스터·호텔·호수·캠핑 숲)·미로 공원(192×192 생울타리 미로, 가운데 전망대), 그리고 경복궁·경리단길 해방촌·동대문디자인플라자·여의도 63빌딩·잠실 롯데월드타워 축소 모형
- 작품은 이 브라우저에 저장하거나 `.json` 파일로 내보내기·가져오기

## 조작
| 키 | 기능 |
|---|---|
| 클릭 / 탭 | 블럭 놓기 |
| 드래그 · 우클릭 드래그 · 휠 | 둘러보기 · 이동 · 확대 |
| R | 회전 |
| M | 손: 블럭을 눌러 고르고 끌어 옮기기 · R 돌리기 · 방향키로 한 칸씩 · Delete 빼기 |
| O | 포즈 |
| T | 지형 |
| N | 낮·밤 |
| X | 빼기 |
| B | 공중 조립판 (Q/E 높이) |
| G | 기어·자동차 움직이기 |
| P | 1인칭 |
| Ctrl+Z | 되돌리기 |

## 기술
한 개의 `index.html` 파일로 되어 있어요. Three.js r128(CDN)을 쓰고, 빌드 과정은 없어요.
