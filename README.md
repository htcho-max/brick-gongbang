# 브릭 공방

브라우저에서 즐기는 3D 블럭 쌓기 게임이에요. 설치 없이 링크만 열면 돼요.

**플레이:** https://htcho-max.github.io/brick-gongbang/

## 할 수 있는 것
- 브릭·플레이트·타일·경사·원형·건축·옆붙임·자연·전투·테크닉 부품 128종으로 쌓기 (판 최대 192×192)
- 전투 부품: 말·대포·깃발·천막·바리케이드·모래주머니·모닥불·가로등
- 지형 도구: 두 곳을 눌러 영역을 정하면 언덕·물·길·모래·풀밭을 한꺼번에 깔거나 영역을 지움
- 밤 모드: 가로등·모닥불·횃불에 불이 들어옴
- 피규어 9종(시민·경찰·우주인·기사·군인·닌자·사무라이·해적·바이킹), 팔·머리·다리(걷기·달리기·무릎·앉기·쓰러짐) 포즈와 칼·총·활·방패 같은 무기
- 기어 맞물려 돌리기, 바퀴·모터·핸들로 자동차 만들어 운전, 프로펠러를 달면 비행기(스페이스로 상승), 물 위에 띄운 배에 모터를 올리면 항해
- 움직이는 세상: ▶ 돌리기를 켜면 걷기·달리기 자세의 피규어가 걸어 다니고, 무기를 든 피규어는 휘두르고 쏘고, 대포가 불을 뿜음
- 📷 사진 · ● 녹화(영상 저장) · 🔊 효과음
- 1인칭으로 피규어가 되어 걸어 다니기(드래그로 방향, W/S 앞뒤 · A/D 옆으로, 벽을 따라 미끄러지고 문틀에 살짝 걸리면 비켜 지나감), 운전석에서 운전하기
- 예시 작품과 따라 만드는 설계도 — 피규어가 들어가 걸을 수 있는 크기: 2층 주택·탱크·여객선·성채·성 공방전·상점가 거리·해적선·사무라이 마을·여객기·경복궁 근정전·경리단길과 해방촌(남산타워까지)·제주 방주교회·부산 송도해수욕장(구름산책로·해상케이블카)·광화문 광장·서서울미술관과 금나래중앙공원, 그리고 경복궁·경리단길 해방촌 축소 모형
- 작품은 이 브라우저에 저장하거나 `.json` 파일로 내보내기·가져오기

## 조작
| 키 | 기능 |
|---|---|
| 클릭 / 탭 | 블럭 놓기 |
| 드래그 · 우클릭 드래그 · 휠 | 둘러보기 · 이동 · 확대 |
| R | 회전 |
| M | 손: 블럭을 눌러 고르고 끌어 옮기기 · R 돌리기 · 방향키로 한 칸씩 · Delete 빼기 |
| O | 포즈 |
| T | 지형 |
| N | 낮·밤 |
| X | 빼기 |
| B | 공중 조립판 (Q/E 높이) |
| G | 기어·자동차 움직이기 |
| P | 1인칭 |
| Ctrl+Z | 되돌리기 |

## 기술
한 개의 `index.html` 파일로 되어 있어요. Three.js r128(CDN)을 쓰고, 빌드 과정은 없어요.
